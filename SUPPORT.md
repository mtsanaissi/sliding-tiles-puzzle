# Support

This project is published as a free package workspace. Support and monetization surfaces are intentionally lightweight so the package stays easy to adopt while still providing a path for deeper collaboration.

## Current support paths

- Bug reports and package issues: [GitHub Issues](https://github.com/mtsanaissi/sliding-tiles-puzzle/issues)
- Release and package context: [README](./README.md)
- Custom integration intake: [Custom integration request issue form](https://github.com/mtsanaissi/sliding-tiles-puzzle/issues/new?template=integration-request.yml)

## Sponsorship and donations

- GitHub Sponsors is the repo-level sponsorship surface configured through `.github/FUNDING.yml`.
- Live sponsor page: [github.com/sponsors/mtsanaissi](https://github.com/sponsors/mtsanaissi)
- Live donation page: [buymeacoffee.com/mtsanaissi](https://buymeacoffee.com/mtsanaissi)

As of 2026-03-13, both links returned `200`, so they are now safe to surface publicly in docs and the demo.

## Custom integration path

Use the integration request issue form when you need:

- a branded or white-label puzzle experience
- implementation help inside an existing React product
- package extension work such as accessibility hardening, analytics hooks, or puzzle persistence
- delivery or consulting discussions tied to a real product timeline

## Future paid layers

These are the named monetization layers reserved for after initial package adoption:

- Custom integration sprints: hands-on implementation and launch support
- White-label puzzle builds: branded, campaign-specific puzzle experiences
- Accessibility and product hardening: keyboard support, QA, and production rollout help

These are service layers around the free package, not features gated inside v1.

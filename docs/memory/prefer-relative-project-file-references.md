# Prefer relative project file references

## Summary

Avoid full file paths when referencing project files unless an absolute path is required to complete the task.

## Context

The user asked for project file references to stay short by default and only use full paths when they are essential.

## Remember

Use repo-relative file references for project files in normal communication. Only use full file paths when they are necessary to accomplish a goal, satisfy a tool requirement, or make a reference unambiguous.
